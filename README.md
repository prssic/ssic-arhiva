# ssic-arhiva

Arhiva foto SSIC — poze din evenimentele asociatiei.

Pozele sunt servite via GitHub Pages: `https://prssic.github.io/ssic-arhiva/`

Structura:
```
<slug>/
  t/  - miniaturi 720px (grila)
  m/  - medii 1800px (lightbox)
  f/  - originale full-res (descarcare)
```

Fișierele sunt generate automat de tool-ul local `SSIC-Galerii-Tool/galerii.py`.
Nu edita manual acest repo.
